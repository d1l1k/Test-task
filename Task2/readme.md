# Задача 2. Требования к новой функциональности публикации товара

## User Story

**Как продавец маркетплейса**,  
я хочу иметь возможность создать карточку товара в личном кабинете и отправить её на публикацию,  
**чтобы** мой товар появился на витрине маркетплейса и стал доступен покупателям.

---

## Use Case

### UC-01. Опубликовать товар на маркетплейсе

### Цель
Позволить продавцу добавить новый товар и опубликовать его на витрине маркетплейса.

### Основной актор
**Продавец**

### Предусловия

1. Продавец зарегистрирован в системе.
2. Продавец авторизован в личном кабинете.
3. У продавца есть доступ к созданию товаров.

### Постусловие

Товар опубликован на витрине маркетплейса.

---

## Основной сценарий

1. Продавец входит в личный кабинет.
2. Переходит в раздел **«Товары»**.
3. Нажимает **«Добавить товар»**.
4. Система открывает форму создания товара.
5. Продавец заполняет:
   - название товара;
   - описание;
   - категорию;
   - цену;
   - количество;
   - фотографии товара.
6. Продавец нажимает **«Отправить на публикацию»**.
7. Система проверяет заполнение обязательных полей.
8. При отсутствии ошибок товар получает статус **«На проверке»**.
9. После проверки товар получает статус **«Опубликован»**.
10. Товар появляется на витрине маркетплейса.

---

## Альтернативные сценарии

### A1. Ошибка заполнения

1. Продавец отправляет товар на публикацию.
2. Система обнаруживает ошибки.
3. Система показывает сообщение о необходимости исправить данные.
4. Продавец исправляет ошибки.

### A2. Сохранение черновика

1. Продавец заполняет часть данных.
2. Нажимает **«Сохранить как черновик»**.
3. Система сохраняет карточку товара.

### A3. Отклонение товара

1. Товар отправлен на публикацию.
2. Проверка выявляет нарушения.
3. Товар получает статус **«Отклонён»**.
4. Продавец исправляет данные и отправляет повторно.

---

## Функциональные требования

- Система должна позволять создавать карточку товара.
- Система должна проверять обязательные поля.
- Система должна позволять сохранять товар как черновик.
- Система должна отображать статус товара.
- Система должна публиковать товар на витрине после успешной проверки.
- Система должна показывать ошибки пользователю.
